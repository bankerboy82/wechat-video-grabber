# 微信视频号视频下载器（配置发行版）

基于开源工具 [ltaoo/wx_channels_download](https://github.com/ltaoo/wx_channels_download)（MIT + Commons Clause）的**开箱即用配置版**。

## 内容

| 文件 | 说明 |
|---|---|
| `wx_video_download.exe` | 工具本体（v2025.10，来自官方发布） |
| `一键启动下载器.bat` | 双击即启动，自动定位目录 |
| `config.yaml` | 预配置（下载目录、并发、代理等） |
| `操作说明.md` | 三步上手教程 + 常见问题 |
| `LICENSE` | 原项目 MIT + Commons Clause 许可证 |

## 快速开始

1. 双击 `一键启动下载器.bat`（首次运行允许安装证书）
2. 电脑版微信里播放目标视频号视频，暂停
3. 点视频下方的「下载」按钮即可

详见 [操作说明.md](操作说明.md)。
